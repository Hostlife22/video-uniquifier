# 应用本地化

桌面图形界面默认英文为源语言，俄语（`ru_RU`）为首个翻译后的语言。切换语言非常方便 — 设置 → **外观 → 语言** 会重新安装翻译器，并将选择保存到 `state.json`。导航、页面标题和主要处理工作流程会立即更新。一些次要屏幕/消息仍需重启以刷新所有字符串。

<a id="available-locales-v09"></a>

## 可用语言环境（v0.9）

|语言环境|状态|覆盖率（CTA 字符串）|维护者|
|---------|------------|------------------------|------------------|
| `en_US` |来源|不适用|video-uniquifier 核心|
| `ru_RU` |已翻译| ≥ 50 %                 |video-uniquifier 核心|
| `zh_CN` |已翻译|已编目字符串的100%|video-uniquifier 核心|
| `es` |部分|核心操作|video-uniquifier 核心|
| `pt_BR` |部分|核心操作|video-uniquifier 核心|

简体中文目录在 `gui/i18n/zh_cn.py` 中维护，并合并到共享源库存。它涵盖导航、页面介绍、设置、处理、播放/比较及所有十个上下文指南。配置文件文件名、编码器标识、路径、日志和用户输入内容保持其原始值。

覆盖率数字是 `SOURCE_KEYS` 的分数
`gui/i18n/translations.py` 在本地化表中有非空条目的比例。它在 CI 时间由
`tests/unit/test_i18n.py::test_coverage_ratio_ru_is_substantial` 检查，如果 `ru_RU` 低于 50% 则失败。没有条目的字符串将按原样回退至源——这是设计使然。

<a id="why-no-ts-qm"></a>

## 为什么没有 `.ts` / `.qm`？

典型的 Qt 管道是 `pylupdate6` → `.ts` → `lrelease` → `.qm`。v0.9 故意跳过它：

* 目录维护在应用程序中——Python 字典便于编辑和审核；
* 贡献者不需要安装 Qt 的开发工具；
* 这个 wheel 精确包含了维护者写入的字节，没有跨版本漂移的构建时编译步骤。

运行时翻译器 `gui/i18n.RuntimeTranslator` 继承 `QTranslator`，重写 `translate()` 并从 `TRANSLATIONS[locale]` 读取译文。`QObject.tr()` 和 `QCoreApplication.translate()` 会经由此翻译器调用，无需修改其他调用位置。

如果未来某个本地化超过几百个字符串，这种权衡会翻转：迁移到 `.ts` + `.qm`，保持相同的公共 API (`install_translator`, `available_locales`)，字典将作为实现细节消失。

<a id="adding-a-new-locale"></a>

## 添加一个新的本地化

1. 打开 `src/video_uniquifier/gui/i18n/translations.py`。
2. 复制 `ru_RU` 块，将键重命名为你的本地化代码（使用 POSIX 形式，例如 `de_DE`, `fr_FR`）。
3. 将每个右边的值替换为你的翻译。省略尚未翻译的键即可回退到英文。**不要**创造新的键——测试套件会拒绝不映射字符串的条目。
   `SOURCE_KEYS`.
4. 保留助记标记（`&Run` → `&Запустить`）。选择一个接近英文的字母；Qt 会突出显示紧跟在 `&` 后的字符。
5. 运行 `pytest tests/unit/test_i18n.py -v`。覆盖测试会在日志行中打印你本地化的百分比。

<a id="adding-a-new-translatable-string-in-the-gui"></a>

## 在 GUI 中添加一个新的可翻译字符串

1. 用 `self.tr("…")` 包裹它（模块级使用则用 `QObject.tr("…")`）。
2. 将准确的源字符串添加到 `SOURCE_KEYS` 中
   `gui/i18n/translations.py`。在其注释部分内保持列表按字母顺序排列。
3. 可选地添加一个 `ru_RU` 条目。缺失条目会回退。

<a id="caveats"></a>

## 注意事项

* 页面标题会在 `LanguageChange` 刷新以及显示页面时刷新。共享
  `gui/i18n/widgets.py` 辅助程序会记住目录支持的标签、按钮、表单标题、占位符、组合框说明和表头的源字符串。它不会翻译编辑器内容或表格数据，并且在更新组合框说明时会阻止小部件信号，以便处理设置保持不变。动态消息在格式化前应使用 `tr()`；技术错误详情和日志可能保持原语言。
* **数字和单位** 当前不会通过格式化处理
  `QLocale` — `1,234` 无论地域设置如何，仍保持用逗号分隔。v1.0 版本将在更多欧洲地区语言支持后重新考量。
* **CLI 仅支持英语。** 翻译面向开发者的输出（Typer 帮助文本、日志行）已明确推迟——受众是全球讲英语的开发者，修改会破坏脚本的 grep 可用性。
