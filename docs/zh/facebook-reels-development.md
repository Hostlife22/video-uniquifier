## PR 审查修正（2026-10-24）

- 清除尚不存在的样片时，保留原片解码器及首帧状态。Windows/Python 3.11 重复测试捕获了原生暂停调用阻塞：修改设置会在解码器初始化期间无谓重置原片。现在仅在 `PlayingState` 下调用原生暂停。回归测试覆盖无样片时的清除、真实样片替换及全部播放状态。pytest 的 C 级看门狗在原有每测试 180 秒限制下输出线程堆栈并终止进程，即使原生调用阻塞 Python 定时器；开发环境需要 pytest 9.1.1 或更高版本。 修复前，第九次 Windows 重复执行阻塞于 `QMediaPlayer.pause()`；修复后，20 次真实预检、样片、导出及取消流程和四项针对性回归测试全部通过。
- 工作进程 JSON 写入和下载时，会将路径规范化并限制到配置的存储根目录，包括符号链接和同级目录前缀。恢复的作业标识符必须为十六进制，格式错误的记录会被跳过。临时 JSON 文件只会在原子替换之前创建并刷新。
- 在调整大小之前会检查 PNG 标志的尺寸：否则过窄的输入可能会超出源像素预算并耗尽工作进程内存。
- 表格选择使用从公共标题几何位置定位的自有复选框，避免在 Linux 本地崩溃后进行私有 Qt 角落发现和 SIP 类型转换。涵盖了调整大小、标题可见性、两种布局方向以及拆卸。翻译会枚举公共标题控件，仅阻止组合框/选项卡/表格信号，并跳过已删除的子孙控件。隐藏的交付页面不再扩大外部页面；表单自动换行长行。小窗口检查涵盖英语、俄语和中文，并对所有十一屏进行了视觉基线审核。
- 真实的 10/30/90 秒导出通过了技术质量保证。原生 Cocoa 验收通过了源文件/样本/导出、解码回放、比较、质量报告和小窗口测试。真实的回环 HTTP 验收通过了身份验证上传、处理、取消、重试、下载以及拒绝逃逸的工件符号链接。
- 证据存放在被忽略的 `out/pr34-review/` 下：核心和桌面验收 JSON、HTTP 验收 JSON、截图以及测试/构建日志。这些检查使用生成的视频素材，并不能替代编辑听审/字幕审查。
- 快速核心合同测试涵盖源限制/HDR/字幕、本地音频选择和修剪图表、响度缓存、节奏诊断和排队取消。干净的快速测试运行：2298 个通过，一个可选分支跳过；核心覆盖率为 81.88%，高于要求的 80% 门槛。已加载的 HD 预览集成检查其新设置页面上的示例操作，并等待 Qt 布局完成。
