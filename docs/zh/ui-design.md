# 界面设计

主要流程是导入 → 调整和预览 → 导出。窗口应立即回答三个问题：我在什么位置，我能做什么，以及接下来会发生什么？保持所有现有处理和队列功能可用。

ui-ux-pro-max 设计系统和 UX 搜索指导了这一方向：渐进披露、可操作的空状态、清晰的选择与焦点，以及稳定的悬停反馈。将这些原则应用到现有的本地 PyQt6 桌面应用程序。使用系统字体并支持中文字符，而不是建议的网页字体组合。保持一个青绿色的操作颜色，而不是在普通工作流程步骤中分配警告颜色。

- 中性石墨黑暗表面；柔和灰色背景上的白色卡片。
- 当前步骤、选定的配置文件和主要操作使用一个强调色。
- 细中性边框，8–12 像素圆角，8/12/16/24 像素间距。
- 紧凑的页面标题和持久的底部处理操作。
- 在空的视频预览中进行导入操作，使用与源字段相同的文件选择器和拖放行为。显示支持的格式并说明原始文件将被保留。
- 三步指示器反映实际状态，无需强制使用向导导航。
- 以普通语言显示的配置文件收益仍然可见；技术编码器/配置文件控制仍保留在高级选项中。
- 推荐的短样本与导出完整视频清晰分开。禁用的操作会说明其前提条件。
- 侧边栏说明阐明高级目标，而不会移动索引或更改键盘快捷键。
- 测试深色/浅色、英语/中文以及最小/大型桌面窗口尺寸。移动端断点不适用于此本地桌面应用程序。
- 紧凑预览会隐藏装饰性上传艺术作品并格式化说明，以便导入操作保持可见。打开诊断工具会暂时隐藏步骤概览，以保留日志和处理结果的空间。
- 尊重减少动画，并保留可见的键盘焦点。不要仅依赖颜色来表示选择或处理状态。
