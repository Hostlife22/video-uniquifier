# 桌面界面指南

本页介绍 PyQt6 桌面客户端的操作流程。事件信号、后台任务与打包说明见[桌面界面参考](gui.md)。

<a id="launching"></a>

## 启动

```bash
pip install video-uniquifier[gui]
video-uniq-gui
```

首次启动会询问是否启用本地遥测，默认关闭，详见[遥测](telemetry.md)。主窗口首先显示视频处理页面。

<a id="sidebar"></a>

## 侧边栏

十个编号页面可通过 Ctrl+1..Ctrl+0 切换。
工作区中的视频交付是额外入口，快捷键为 Ctrl+Shift+R。

| 编号 | 页面 | 用途 |
|---|---|---|
| 1 | 视频处理 | 选择源文件与输出，应用配置并检查结果 |
| 2 | 批量处理 | 处理文件夹并跟踪各文件 |
| 3 | 自动调参 | 根据质量与相似度约束搜索配置参数 |
| 4 | 质量报告 | 打开报告或比较输入/输出文件 |
| 5 | 配置文件 | 编辑效果、查看 YAML 和社区配置库 |
| 6 | 历史记录 | 查找以往任务及其视频和报告 |
| 7 | 参考库 | 管理自己的本地指纹参考 |
| 8 | 处理队列 | 安排待处理任务并控制后台工作进程 |
| 9 | 实验 | 生成授权变体并记录观察结果 |
| 10 | 设置 | 主题、语言、默认配置与可选集成 |
| — | 视频交付 | 四步 Reels 准备、样片检查与导出 |

视频处理分为 **视频与预览 → 处理设置 → 进度与结果**。输出路径会自动建议。
初次比较可使用 `soft` 或已保存的配置。高级设置用于选择编码器、编辑配置或自动调参。
出现错误时会打开任务日志。

<a id="keyboard-shortcuts-run-screen"></a>

## 视频处理快捷键

| 快捷键 | 操作 |
|---|---|
| `Ctrl+R` | 开始处理 |
| `Ctrl+T` | 自动调参 |
| `Space` | 暂停 / 继续 |
| `Esc` | 取消 |
| `Ctrl+S` | 保存设置 |
| `Ctrl+P` | 检查视频 |
| `Ctrl+Q` | 打开质量报告 |
| `Ctrl+1..0` | 切换侧边栏页面 |

<a id="settings-language-v09-r5"></a>

## 设置 → 语言

语言选择保存到 `state.json`，导航、标题与主要页面无需重启即可更新。
部分次要对话框和技术消息可能在下次启动前保留原语言。
覆盖范围和新增译文规则见[应用本地化](i18n.md)。

<a id="accessibility-v100-r6"></a>

## 无障碍

WCAG 2.1 AA 检查包括两种主题下的可见焦点边框、控件名称与角色、最小点击目标和对比度。
完整符合性说明、已知限制与屏幕阅读器手动检查见[无障碍](accessibility.md)。

<a id="screenshots"></a>

## 截图

已审核的视觉基线位于 `tests/visual/__snapshots__/`，`host.json` 记录截图平台。
macOS 与 Linux 的原生字体渲染不同。仅在有意更新界面时使用 `make test-visual-update`，
并在相同平台审查截图；`make test-visual` 对比现有基线。
独立布局和行为测试会在两种主题、980×640 窗口下检查全部十一个页面，
包括键盘操作、源文件保留与编码器选择。
