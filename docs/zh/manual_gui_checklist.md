# 手动界面检查

运行 `scripts/manual_gui_smoke.sh` 启动带有生成的 5 秒示例剪辑的 GUI。按照每个编号步骤操作；在问题跟踪器中记录 FAIL 并附上屏幕截图和复现步骤。

目标：捕捉 `make test-gui` 无法处理的任何问题——拖放、图表渲染、快捷键、对话框/文件选择器、主题切换、重启后的持久化。

<a id="1-run-screen-golden-path"></a>

## 1. 运行屏幕——黄金路径
- [ ] 将示例剪辑拖入输入选择器（或使用“选择…”）。显示文件名和目录；长路径会用完整路径工具提示省略。
- [ ] 验证建议的输出与源文件分开；如需，可以选择其他路径。
- [ ] 点击 **检查视频** ——结果行会在面板中显示（通行或警告，在示例中不会 FAIL）。
- [ ] 点击 **开始处理** ——进度分数前进，时间轴显示绿色片段。
- [ ] 完成后，状态变为“已完成”，结果操作滚动到视图中，并启用打开质量报告。展开测量指标以检查 KPI 标签。
- [ ] 点击打开质量报告 —— 系统浏览器将打开 `.qa.html`。

<a id="2-run-screen-cancel"></a>

## 2. 运行屏幕 —— 取消
- [ ] 开始运行，中途点击 **取消** —— 状态先变为“正在取消…”，然后变为“已取消”。
- [ ] 取消后，开始处理按钮重新启用。

<a id="short-sample-comparison-and-processing-stages"></a>

## 简短样本、比较和处理阶段

- [ ] 在本地预览原始播放，而不启动编码。
- [ ] 源缩略图和五帧胶片条异步显示；更换源将丢弃旧帧。
- [ ] 配置文件卡显示可读的俄文和英文图像/音频描述，包括在 980×640 下。选择卡将更新配置文件；自定义配置文件清除卡选择。
- [ ] 点击/拖动胶片条或使用箭头键；HH:MM:SS.cc 输入会跟随选择。在原播放器中使用此时间样本设置相同的起始点。
- [ ] 展开测试一个短片段，选择起点和 10/15/20 秒，然后处理样本。短源会在其末端被限制。
- [ ] 样本完成后会打开前/后视图。原始文件、完整目标和运行历史保持不变。
- [ ] 刷动并播放两个面板；在原始/结果音频之间切换，并确认只能听到一个音轨。暂停会使两者静音。
- [ ] 在暂停状态下前后逐帧移动，包括可变帧率剪辑。显示的帧会按相邻时间戳变化。
- [ ] 切换并排/原始/结果以及适应/100%。检查像素细节；在 Retina 显示屏上滚动较大的帧。
- [ ] 切换到可拖动分隔条。拖动滑块并使用左右键、Home/End键；验证左侧的源内容和右侧的结果内容及匹配的帧位置。
- [ ] 选择50/200/400%并拖动图像；两侧同时移动。在并排模式下，滚动或拖动任意一张图片，并确认另一张图片同步跟随。
- [ ] 保存样本… 会写入一个相同的MP4文件，即使关闭应用程序也能保留。原路径、符号链接和硬链接目标都被拒绝。取消操作会保持任何现有的目标不变，并允许重试。
- [ ] 在处理样本时导航到设置；进度仍显示在全局横幅中。返回任务时会选择右侧屏幕；完成的任务会消失。可以在同时运行任务和批量任务之间进行选择。
- [ ] 对于节奏改变的结果，选择按持续时间同步；验证共享的播放进度，而无需假设语义场景对齐。
- [ ] 在 760×540 分辨率下，比对控件仍可使用。在查找帧时关闭对话框；应用程序仍然响应。
- [ ] 在完整运行期间，阶段会继续进行保存和质量检查。阶段 ETA 在转换时重置；暂停会冻结已用时间，未知/停滞的进度没有数值 ETA。
- [ ] 在样本准备和 QA 过程中可取消。控件允许重试，结果标记为已取消。
- [ ] HDR 输入会禁用样本按钮并显示解释；完整处理仍可用。
- [ ] 已知 PQ/HLG HDR 比对帧会禁用栅格分割器；本地面板仍可用。在适合的 HDR 设备上单独确认显示颜色。

<a id="3-batch-screen"></a>

## 3. 批处理屏幕
- [ ] 选择包含 2 个或以上 mp4 的目录。表格预览会列出它们。
- [ ] 将模式更改为 `*.mov` — 预览会更新/清除。
- [ ] 运行批处理，观察每个文件状态循环：排队 → 运行 → 完成。
- [ ] 当某个文件出错时，继续出错切换明显改变失败行为。

<a id="4-calibrate-screen"></a>

## 4. 校准屏幕
- [ ] 选择样本作为校准输入。
- [ ] 将迭代次数设置为 1，然后点击 **查找设置**（短——小片段下不到 1 分钟）。
- [ ] 完成后，**保存调优的配置文件为…** 已启用。
- [ ] 保存到临时 YAML 文件并确认文件存在。

<a id="5-qa-viewer"></a>

## 5. QA 查看器
- [ ] 切换到 **打开现有** 标签；选择步骤 1 的 `.qa.html`。
- [ ] 当嵌入查看器可用时报告呈现；浏览器回退仍可用。
- [ ] **在浏览器中打开** 打开 HTML 报告。

<a id="6-profile-editor"></a>

## 6. 配置文件编辑器
- [ ] 从下拉菜单选择 `cid_aware` —— 表格填充转换内容。
- [ ] 编辑一个参数，点击 **另存为…**，写入新路径。
- [ ] **重新加载列表** 会获取新的配置文件。

<a id="7-history"></a>

## 7. 历史记录
- [ ] 验证步骤1的运行是否出现在历史表中。
- [ ] 应用过滤器 — 行会实时更新。
- [ ] **全部清除** 会提示确认并清空表格。

<a id="8-queue"></a>

## 8. 队列
- [ ] **浏览…**+**在此初始化队列** 在空目录上 — 按钮从禁用切换到启用。
- [ ] **添加文件…** 添加示例。统计标签显示待处理=1。
- [ ] **▶ 开始工作进程** — 示例处理；完成后统计显示完成=1。
- [ ] **停止** 在活动处理过程中可安全中止。

<a id="9-validation"></a>

## 9. 校验
- [ ] 步骤1 → 选择样本 + 2 个变体 + 生成；行会出现。
- [ ] 第2步 → 记录每行CID结果（通过/失败）并保存CSV。
- [ ] 第3步 → 运行相关分析；输出框显示报告。

<a id="10-settings-corpus-theme-switch"></a>

## 10. 设置 + 语料库 + 主题切换
- [ ] 切换主题深色↔浅色 — 每个可见屏幕立即重设皮肤。
- [ ] 选择默认配置文件并保存 — 重新打开设置以确认持续性。
- [ ] 语料库 → 添加文件 → 条目出现。移除 → 行消失。
- [ ] 关闭应用并重新启动 — 最近项目、选定的配置文件、语言和主题在重启后保持。

<a id="11-misc"></a>

## 11. 其他
- [ ] 调整窗口大小 — 无重叠控件，无标签被裁剪。
- [ ] 使用键盘焦点 + 空格展开高级设置和活动日志。
- [ ] 在980×640分辨率下，主要操作保持可见，而页面滚动。
- [ ] 切换语言：导航、页面标题和主要工作流程更新，无空白控件。
- [ ] 正常会话后 stderr 上无控制台错误。
