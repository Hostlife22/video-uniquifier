# video-uniquifier

Обработка и перекодирование собственных видео и материалов, на использование которых
у вас есть лицензия. Просматривайте изменения, сравнивайте исходник с результатом
и обрабатывайте отдельные файлы или пакеты через приложение, CLI или локальный веб-интерфейс.

<a id="start-here"></a>

## С чего начать

- [Установка](install.md): Python, готовые сборки приложения, FFmpeg и первый запуск.
- [Начало работы](getting-started.md): анализ исходника, проверка профиля и кодирование.
- [Руководство по интерфейсу](gui-walkthrough.md): исходники, образцы, настройки и результаты.
- [Подготовка видео / Reels](facebook-reels.md): четыре шага подготовки вертикального
  видео, CLI и HTTP API, таймлайн сцен и технические отчёты качества.
- [Веб-интерфейс и Docker](web.md): локальный интерфейс в браузере или контейнер.

```sh
pip install "video-uniquifier[gui] @ git+https://github.com/Hostlife22/video-uniquifier.git@v2.2.0"
python -c "from importlib.resources import files; from pathlib import Path; Path('review-soft.yaml').write_bytes(files('video_uniquifier').joinpath('profiles/soft.yaml').read_bytes())"
video-uniq-gui
video-uniq probe input.mp4
video-uniq preflight input.mp4 --profile review-soft.yaml
video-uniq run input.mp4 --profile review-soft.yaml --out output.mp4
```

Для установки из исходников нужны Python 3.11+ и FFmpeg/FFprobe в PATH.
Дополнительные возможности требуют указанных в документации зависимостей,
например `[scene]` для определения сцен.

## Обработка и проверка результата

- [Профили](profiles.md) и [справочник преобразований](transform_reference.md) описывают
  геометрию, изменения изображения и звука, совместимость с HDR и параметры обработки.
- [Архитектура](architecture.md) объясняет возобновление по сегментам, ограничение
  ресурсов и общее ядро для приложения, CLI и веб-интерфейса.
- [Отчёты качества](qa_report.md) разделяют техническую корректность, метрики
  восприятия и диагностическую похожесть. Просмотрите изображение и прослушайте звук.
- [Распределённая обработка](distributed.md) описывает работу с проверенной общей
  файловой системой; [проверка оборудования](hardware_qualification.md) — ограничения устройств.

Приложение и документация доступны на английском, русском и упрощённом китайском.
Язык сайта переключается в шапке. Структура исходников и правила обновления переводов
описаны в разделе [«Языки документации»](documentation.md).
