# Обнаружение копий SSCD

> Добавлено в v0.8.0 (R4 — метрика; R6 — калибровка по SSCD).

SSCD (Self-Supervised Copy Detection) — это модель встраивания изображений для обнаружения копий от Meta, [оцененная на DISC/Copydays](https://github.com/facebookresearch/sscd-copy-detection). Этот проект применяет её к выбранным кадрам видео в качестве внутренней диагностики для контента, которым владеет компания / на который имеются лицензии. Временная выборка/выравнивание — это отдельная процедура и не воспроизводит YouTube Content ID или визуальное качество человека.

В `video-uniquifier` SSCD является **по желанию**: модель не включена автоматически, torch не является обязательной зависимостью, и метрика выполняется только по вашему запросу.

<a id="install"></a>

## Установка

```bash
pip install 'video-uniquifier[ml]'
```

Это загружает актуальную пару Torch/torchvision. При первом использовании
~94 МБ `sscd_disc_mixup` TorchScript контрольной точки загружаются с официального CDN Meta в `~/.cache/video_uniquifier/models/` и проверяются с помощью SHA-256. Несовпадающий кешированный файл удаляется и загружается заново — хэш закреплен в `core/qa/sscd.py::_MODEL_SHA256`, поэтому замена CDN приведет к явной ошибке, а не к тихому использованию неизвестных весов.

Поддерживается только официальный артефакт TorchScript. В исходном проекте Meta не публикуется контрольная точка ONNX; пользовательская бэкенд-система должна быть явно предоставлена через `model_loader`. Исходный проект SSCD распространяется под лицензией MIT; ознакомьтесь с этой лицензией перед повторным распространением контрольной точки.

Intel macOS является ограниченным исключением: на PyPI доступна только версия Torch 2.2.2 для этой архитектуры, и текущие базы данных уязвимостей сообщают об уведомлениях безопасности для этой линии. Поэтому проект квалифицирует эту комбинацию только для встроенной контрольной точки SSCD, точный SHA-256 которой указан выше. Не загружайте ненадежные модели Torch на Intel macOS; используйте Apple Silicon, Linux, Windows или внедренный не-Torch бэкенд, когда требуется полностью исправленная среда ML.

Если `[ml]` не установлен, каждая публичная точка входа SSCD вызывает ошибку.
`PipelineError` с указанной выше подсказкой установки. Остальная часть инструмента — конвейер ffmpeg, QA chromaprint, калибровка — остается пригодной для использования.

<a id="in-the-qa-report"></a>

## В отчете QA

```bash
video-uniq qa source.mp4 output.mp4 --sscd
# or, for finer per-frame resolution:
video-uniq qa source.mp4 output.mp4 --sscd --sscd-frames 64
```

Консоль выводит заголовок с диапазоном (`high` / `caution` / `clean`), а HTML-отчет (`<out>.qa.html`) отображает закодированную цветами тепловую карту по кадрам вместе с существующими блоками VMAF + chromaprint. JSON-сопроводитель получает три плоских поля:

* `sscd_mean` — средний косинус между совпадающими парами кадров
* `sscd_min` — наименее похожая пара (полезно для обнаружения одного выброса)
* `sscd_per_frame` — массив косинусов, выровненный 1:1 с сеткой исходных кадров

<a id="threshold-bands"></a>

### Пороговые диапазоны

Это сохраненные корзины для отображения проекта, а не откалиброванные пороги детектора или прямые преобразования кривых точности DISC21:

|Среднее сходство|Диапазон|Чтение|
|----------------:|:----------|:-------------------------------------------|
| ≥ 0.85          | `high`    |Высокое внутреннее сходство источника и выхода|
| 0.65 – 0.85     | `caution` |Смешанный результат; проверьте качество и выравнивание|
| < 0.65          | `clean`   |Низкое сходство; проверьте возможную потерю качества|

Эти устаревшие названия диапазонов являются диагностическими метками, а не целями «пройдено/не пройдено». Более низкий балл может означать разрушительные преобразования, временное несоответствие или сбой измерений; его необходимо рассматривать вместе с результатами VMAF/SSIM, аудио и медийного контракта.

<a id="in-calibration"></a>

## В калибровке

```bash
video-uniq calibrate input.mp4 \
  --base profiles/cid_aware.yaml \
  --out tuned.yaml \
  --metric sscd \
  --target 0.8
```

`--metric sscd` заменяет предсказатель Chromaprint версии 0.5 на оценщик, управляемый SSCD. Усечённая средняя косинусная мера SSCD передаётся напрямую в калибровку: более высокие значения означают большее сходство, а сходимость требует `mean_similarity <= target`, при этом также выполняется независимый базовый уровень качества. Цели SSCD и Chromaprint не взаимозаменяемы и должны калиброваться отдельно на авторизованном корпусе.

Chromaprint по умолчанию не изменён: пропуск `--metric` запускает v0.7 смешанный максимум pHash/аудио диагностики, включая требование `fpcalc`, если источник содержит аудио. Отсутствующие отпечатки не могут пройти его систему проверки.

GUI: на экране Калибровка есть выпадающий список **Метрика** рядом со спиннером длительности тестового клипа.

<a id="determinism"></a>

## Детерминизм

Одинаковые входные байты + одинаковый файл модели + `torch.set_grad_enabled(False)` + фиксированная сетка кадров → идентичные биты эмбеддингов, идентичные биты косинусов. Два последовательных вызова `compute_sscd` возвращают равные кортежи `SSCDResult`. Это важно для возобновления: профиль, откалиброванный SSCD, повторно запускается с тем же результатом на том же источнике, так что профиль, настроенный сегодня, по-прежнему сходится на том же клипе в CI завтра.

<a id="public-api"></a>

## Публичное API

```python
from video_uniquifier.core.qa.sscd import compute_sscd, sscd_band, SSCDResult

result: SSCDResult = compute_sscd(
    source=Path("in.mp4"),
    output=Path("out.mp4"),
    frame_count=32,            # default — 32 uniform samples
    cancel_token=token,        # optional, including during FFmpeg extraction
    model_loader=None,         # test-only injection seam
)
print(result.mean_similarity, sscd_band(result.mean_similarity))
```

`model_loader` существует, чтобы модульные тесты могли использовать заглушку сети без установки многосот-МБ колеса torch (см.
`tests/unit/test_sscd_offline.py`).

<a id="cancellation"></a>

## Отмена

`compute_sscd` — это вызов, нагружающий CPU на 5–10 секунд при умолчательном значении frame_count. Параметр `cancel_token` проверяется между каждой фазой (`model_load`, `extract_source`, `extract_output`, `embed`, `cosine`). Извлечение середины также использует общий раннер, поэтому отмена завершает весь процесс FFmpeg, вместо того чтобы ждать окончания всех поисков.

`calibrate(metric="sscd")` передает один и тот же токен в каждую итерацию, соответствуя поведению v0.5.5 A6 для пути chromaprint.

<a id="architecture-notes"></a>

## Примечания к архитектуре

* **Ленивая загрузка**: `import torch` находится внутри `compute_sscd`, а не на верхнем уровне модуля. Импорт `video_uniquifier.core.qa.sscd` бесплатный.
* **Равномерная выборка временной шкалы**: поиски середины охватывают всю исходную временную шкалу без декодирования каждого предыдущего кадра многочасового файла. Все поиски для одного файла выполняются через один процесс FFmpeg с однопоточным вводом декодера. Образцы масштабируются до 288×288 и получают нормализацию mean/std из ImageNet перед инференсом.
* **Косинусная мера попарно**: модель уже выдает L2-нормализованные векторы; явное указание `clamp([-1, 1])` служит страховкой от дрейфа чисел с плавающей запятой.
* **Слой плагина не изменен**: SSCD полностью находится в `core/qa/`, поэтому сторонний плагин трансформации никогда не должен знать о его существовании.

* [`docs/en/qa_report.md`](qa_report.md) — JSON/HTML-схема артефакта QA

* [`docs/en/profiles.md`](profiles.md) — схема профиля (без полей SSCD; метрика на один запуск)

Запрошенные временные метки, наибольший измеренный косинус, количество пар, хеш модели и предобработка фиксируются в заметках QA. Вставки между выборками могут быть пропущены. Статические матрицы не могут установить временной сдвиг; регистрация недоступна для этой неоднозначности, в то время как необработанный попарный косинус остается действительной диагностической выборкой.
