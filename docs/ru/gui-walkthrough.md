# Руководство по интерфейсу

Обзор экранов настольного клиента PyQt6. Сигналы, фоновые задачи и упаковка приложения
описаны в [техническом справочнике GUI](gui.md).

<a id="launching"></a>

## Запуск

```bash
pip install video-uniquifier[gui]
video-uniq-gui
```

При первом запуске появляется предложение включить локальную телеметрию.
По умолчанию она отключена; подробности — в разделе [«Телеметрия»](telemetry.md).
Главное окно открывается на странице обработки видео.

<a id="sidebar"></a>

## Боковая панель

Десять пронумерованных экранов доступны через Ctrl+1..Ctrl+0.
Подготовка видео — дополнительный раздел рабочей области с сочетанием Ctrl+Shift+R.

| № | Экран | Назначение |
|---|---|---|
| 1 | Обработка видео | Выбрать исходник и результат, применить профиль и проверить выходной файл |
| 2 | Пакетная обработка | Обработать папку и следить за каждым файлом |
| 3 | Автоподбор | Найти параметры с учётом ограничений качества и похожести |
| 4 | Отчёты качества | Открыть отчёт или сравнить пару исходник/результат |
| 5 | Профили | Изменить эффекты, просмотреть YAML и каталог сообщества |
| 6 | История | Найти прошлые задачи, видео и отчёты |
| 7 | Библиотека эталонов | Управлять собственными локальными отпечатками |
| 8 | Очередь обработки | Организовать задания и управлять фоновыми исполнителями |
| 9 | Эксперименты | Создавать разрешённые варианты и записывать наблюдения |
| 10 | Настройки | Тема, язык, профиль по умолчанию и интеграции |
| — | Подготовка видео | Четыре шага Reels, проверка образца и экспорт |

В обработке видео следуйте страницам **Исходник и предпросмотр → Настройки обработки →
Прогресс и результат**. Путь результата предлагается автоматически. Начните с `soft`
или сохранённого профиля. Дополнительные настройки открывают выбор кодировщика,
редактор профилей и автоподбор. При ошибках открывается журнал событий.

<a id="keyboard-shortcuts-run-screen"></a>

## Сочетания клавиш на странице обработки

| Сочетание | Действие |
|---|---|
| `Ctrl+R` | Начать обработку |
| `Ctrl+T` | Автоподбор профиля |
| `Space` | Пауза / возобновление |
| `Esc` | Отмена |
| `Ctrl+S` | Сохранить настройки |
| `Ctrl+P` | Проверить видео |
| `Ctrl+Q` | Открыть отчёт качества |
| `Ctrl+1..0` | Перейти на экран боковой панели |

<a id="settings-language-v09-r5"></a>

## Настройки → Язык

Выбор языка сохраняется в `state.json`. Навигация, заголовки и основные страницы
обновляются без перезапуска. Некоторые вторичные диалоги и технические сообщения
могут сохранять исходный язык до следующего запуска. Состояние перевода и правила
добавления строк описаны в разделе [«Локализация приложения»](i18n.md).

<a id="accessibility-v100-r6"></a>

## Доступность

Проверки WCAG 2.1 AA включают видимый контур фокуса в обеих темах,
доступные имена и роли элементов, минимальные размеры целей и контраст.
Заявление о соответствии, ограничения и ручные проверки со скринридером
опубликованы в разделе [«Доступность»](accessibility.md).

<a id="screenshots"></a>

## Скриншоты

Проверенные визуальные эталоны находятся в `tests/visual/__snapshots__/`;
платформа захвата записана в `host.json`. Шрифты различаются между macOS и Linux.
`make test-visual-update` используют для намеренного обновления эталонов с просмотром
изображений на той же платформе; `make test-visual` сравнивает их.
Отдельные проверки размещения и поведения проходят все одиннадцать экранов
при 980×640 в обеих темах, включая клавиатуру, сохранение исходника и выбор кодировщика.
