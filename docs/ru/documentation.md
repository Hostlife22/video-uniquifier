# Языки документации

Документация и README доступны на английском, русском и упрощённом китайском.
Переключатель в шапке сайта открывает ту же страницу на другом языке.
Одновременно меняются навигация, элементы поиска и содержание страницы.

<a id="source-layout"></a>

## Структура исходников

```text
docs/
├── en/                 # English pages; published at the site root
├── ru/                 # Russian pages; published under /ru/
├── zh/                 # Simplified Chinese pages; published under /zh/
└── screenshots/        # Shared images
README.md               # English repository introduction
README.ru.md            # Russian repository introduction
README.zh-CN.md         # Simplified Chinese repository introduction
```

Относительные имена страниц совпадают во всех языках: например,
`docs/ru/install.md` соответствует `docs/en/install.md` и `docs/zh/install.md`.
Английская версия публикуется в корне сайта, русская — в `/ru/`, китайская — в `/zh/`.
Существующие английские URL продолжают работать.

Ссылки выбора языка в README работают прямо на GitHub. Каждый README ведёт
в свою языковую папку. Изображения общие; язык приложения на скриншоте может отличаться.

<a id="editing-and-translating"></a>

## Обновление переводов

При изменении или добавлении страницы обновляйте все три версии.
Команды CLI, пути API, ключи настроек, имена файлов, единицы и численные ограничения
должны оставаться согласованными. Переводятся пояснения и подписи, а не идентификаторы.
Исторические результаты тестов сохраняют даты и относятся к указанной ревизии.

Внутри языковой папки используйте соседние ссылки: `[Установка](install.md)`.
Общие изображения подключаются через `../screenshots/filename.png`.
Явные английские якоря у переведённых заголовков сохраняют ссылки на разделы.
Переводы навигации находятся в `mkdocs.yml`; переключатель предоставляют Material
и mkdocs-static-i18n. Общие изображения подключаются через резервные ресурсы языка
по умолчанию. До сборки CI сверяет все страницы и отклоняет отсутствующие переводы,
поэтому английская подстановка не может попасть в публикацию вместо перевода.

<a id="build-and-verify"></a>

## Сборка и проверка

Запускайте из корня репозитория:

```sh
python -m pip install -e '.[docs]'
make docs-build
make docs-serve
```

`make docs-build` сверяет набор страниц и ссылки README, собирает три языка
в строгом режиме и проверяет переключатель и поисковый индекс готового сайта.
`make docs-serve` запускает локальный просмотр с автоматическим обновлением.
CI выполняет сборку при изменении документации, README, конфигурации и инструментов
проверки и сохраняет весь многоязычный сайт как артефакт. При выпуске тега существующий
этап публикации разворачивает этот артефакт на GitHub Pages.

Проверка переключателя и поиска в Chromium на широком и мобильном экране, как в CI:

```sh
python -m pip install -e '.[docs,docs-test]'
python -m playwright install chromium
python tools/check_docs_browser.py --site-dir _site
```
