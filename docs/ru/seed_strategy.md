# Стратегия случайного зерна

Случайные преобразования выбирают параметры на основе `Plan.run_seed`. Поле `Profile.seed_strategy` определяет, повторять ли этот выбор при новом запуске или создавать новый вариант. Используйте варианты только для собственных видео или материалов, которые разрешено изменять и распространять по лицензии.

<a id="the-four-strategies"></a>

## Четыре стратегии

| Стратегия | Источник зерна | Поведение |
|---|---|---|
| `fixed` | `Profile.seed` или 0, если значение не задано; приведение к uint32 | Повторяет тот же случайный выбор параметров |
| `per_run` | Новое случайное uint32 для нового запуска | Меняет параметры между независимыми запусками |
| `per_file` | Первые четыре байта SHA-256 от `source.path.as_posix()` | Повторяет выбор для той же строки пути |
| `divergent` | Новое зерно запуска и производное зерно каждого видеосегмента | Меняет видеопараметры между сегментами |

`per_file` хеширует путь, а не содержимое файла. Перенос файла или другой путь могут изменить зерно; изменение содержимого по прежнему пути не меняет этот способ вычисления. План обработки отдельно идентифицируется хешем плана.

<a id="configure-a-profile"></a>

## Настройка профиля

Скопируйте штатный профиль и задайте стратегию:

```yaml
seed_strategy: fixed
seed: 42
```

Для независимых вариантов используйте `per_run`. Для экспериментов с разными видеопараметрами по сегментам — `divergent`; название не обещает определённого решения внешней системы обнаружения.

```yaml
seed_strategy: divergent
```

Зерно сегмента — первые четыре байта SHA-256 от UTF-8-строки `"{plan_hash}:{segment_idx}:{run_seed}"`, прочитанные как беззнаковое целое с порядком байтов big-endian. Одинаковые входные значения дают одинаковое зерно сегмента. Обработка полного аудио сохраняет зерно всего запуска.

<a id="resume-and-new-variants"></a>

## Возобновление и новые варианты

Контрольная точка в `state.json` сохраняет зерно запуска. Возобновление того же совместимого плана повторно использует выбранные параметры и готовые сегменты. `--new-variant` запрашивает новый вариант для `per_run` и `divergent`; `fixed` и `per_file` остаются детерминированными.

```bash
video-uniq run master.mp4 --profile p.yaml --out result.mp4
video-uniq run master.mp4 --profile p.yaml --out result.mp4 --new-variant
```

Здесь `p.yaml` — сохранённый штатный профиль. Для каждой одновременно выполняемой задачи используйте отдельные выходной и рабочий каталоги.

<a id="reproducibility-limits"></a>

## Ограничения воспроизводимости

Зерно воспроизводит случайный выбор параметров. Оно не гарантирует одинаковые байты результата между версиями кодировщика, расписаниями потоков, устройствами, сборками ОС или метаданными контейнера. Для воспроизведения сохраняйте контрольную сумму исходника, профиль, хеш плана, фактическое зерно и версии инструментов. Проверяйте корректность декодированного видео и используйте совмещённый эталон для сравнения качества.

Локальные оценки сходства не предсказывают решения Content ID, оригинальность на платформе, охват или разрешение на публикацию. Перед использованием разрешённого производного видео проверьте изображение, диалоги и субтитры.

<a id="implementation-and-tests"></a>

## Реализация и тесты

- `core/seed_resolver.py`: выбор зерна запуска и вычисление зерна сегмента.
- `core/segmenter.py::_plan_for_segment`: копии плана для видеосегментов.
- `core/orchestrator.py::build_plan`: первоначальный выбор зерна.
- `tests/unit/test_seed_resolver.py` и `tests/unit/test_divergent_seed.py`: детерминированное вычисление, поведение стратегий и границы uint32.
