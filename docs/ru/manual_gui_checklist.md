# Ручная проверка GUI

Запустите `scripts/manual_gui_smoke.sh`, чтобы открыть GUI с сгенерированным 5-секундным образцом клипа. Выполняйте каждый пронумерованный шаг; фиксируйте FAIL с экраном + воспроизведением в системе отслеживания проблем.

Цель: уловить все, что `make test-gui` не может — перетаскивание, отображение графиков, горячие клавиши, диалоговые окна/выбор файлов, переключение тем, сохранение состояния после перезапуска.

<a id="1-run-screen-golden-path"></a>

## 1. Экран обработки — основной сценарий
- [ ] Перетащите образец клипа в селектор ввода (или используйте Выбрать…). Имя файла и директория отобразятся; длинные пути сокращаются с подсказкой полного пути.
- [ ] Убедитесь, что предложенный вывод отделен от исходного; при желании выберите другой путь.
- [ ] Нажмите **Проверить видео** — строки результатов отображаются в панели (PASS или WARN, FAIL на образце отсутствует).
- [ ] Нажмите **Начать обработку** — прогресс увеличивается, на таймлайне сегменты отображаются зелёным.
- [ ] После завершения статус становится "Готово", действия с результатами прокручиваются в видимую область, и становится доступной кнопка Открыть отчет о качестве. Разверните Измеренные метрики, чтобы проверить показатели KPI.
- [ ] Нажмите Открыть отчет о качестве — системный браузер открывает `.qa.html`.

<a id="2-run-screen-cancel"></a>

## 2. Экран обработки — отмена
- [ ] Начните выполнение, нажмите **Отменить** во время выполнения — статус меняется на "Отмена…", затем на "Отменено".
- [ ] Кнопка начала обработки снова становится доступной после отмены.

<a id="short-sample-comparison-and-processing-stages"></a>

## Этапы: короткий образец, сравнение и обработка

- [ ] Предварительный просмотр оригинальных проигрываний локально без начала кодирования.
- [ ] Эскиз источника и пять кадров кинопленки появляются асинхронно; изменение источника сбрасывает старые кадры.
- [ ] Карточки профиля показывают читаемые описания изображений/аудио на русском и английском языках, включая разрешение 980×640. Выбор карточки обновляет профиль; пользовательские профили снимают выбор карточки.
- [ ] Щелкайте/перетаскивайте пленку или используйте стрелки; ввод HH:MM:SS.cc следует за выбором. Используйте это время для примера в оригинальном проигрывателе, чтобы установить тот же старт.
- [ ] Расширьте Тест короткого фрагмента, выберите начало и 10/15/20 секунд, затем Обработайте пример. Короткий источник обрезается в конце.
- [ ] Завершение примера открывает До / После. Оригинальный файл, полный каталог назначения и история выполнения остаются без изменений.
- [ ] Перематывайте и воспроизводите обе панели; переключайтесь между оригинальной и обработанной аудиодорожкой и убедитесь, что слышна только одна звуковая дорожка. Пауза выключает звук на обеих панелях.
- [ ] Перемещайтесь вперед и назад при паузе, включая клип с переменной частотой кадров. Отображаемый кадр изменяется на один соседний временной штамп.
- [ ] Переключитесь между бок о бок/оригинал/результат и Подогнать/100%. Проверьте детали пикселей; прокручивайте большие кадры на дисплее Retina.
- [ ] Переключитесь на Перетаскиваемый делитель. Перетащите ручку и используйте Влево/Вправо, Home/End; проверьте исходник слева, результат справа и совпадение позиций кадров.
- [ ] Выберите 50/200/400% и перетащите изображение; обе стороны двигаются вместе. В режиме бок о бок прокручивайте/перетаскивайте любое изображение и убедитесь, что другое следует за ним.
- [ ] Сохранить образец… создаёт идентичный MP4, который сохраняется после закрытия приложения. Путевые, символические ссылки и ссылки на жесткий диск отклоняются. Отмена сохраняет любой существующий путь назначения и позволяет повторную попытку.
- [ ] Перейдите в Настройки во время обработки образца; прогресс остаётся в глобальном баннере. Возврат к задаче выбирает правильный экран; выполненные задачи исчезают. Выберите между одновременным запуском/пакетными задачами.
- [ ] Для результата с измененной скоростью выберите «Синхронизация по длительности»; проверьте прогресс совместной презентации, не предполагая семантического выравнивания сцены.
- [ ] При разрешении 760×540 элементы управления сравнением остаются доступными. Закройте диалог во время поиска кадра; приложение остается отзывчивым.
- [ ] Во время полного запуска этапы продолжаются через сохранение и проверку качества. ETA этапа сбрасывается при переходах; пауза замораживает прошедшее время, а неизвестный/застрявший прогресс не имеет численного ETA.
- [ ] Отмена во время подготовки образцов и во время QA. Элементы управления позволяют повторную попытку, и результат получает пометку «Отменено».
- [ ] Ввод HDR отключает кнопку образца с пояснением; полная обработка остается доступной.
- [ ] Известные кадры сравнения PQ/HLG HDR отключают делитель растров; родные панели остаются доступными. Подтвердите цвет отображения отдельно на подходящем HDR-оборудовании.

<a id="3-batch-screen"></a>

## 3. Пакетная обработка
- [ ] Выберите каталог с 2 и более mp4. Таблица предварительного просмотра их перечисляет.
- [ ] Измените шаблон на `*.mov` — предварительный просмотр обновляется / очищается.
- [ ] Запустите пакетную обработку, наблюдайте за циклом статусов файлов: в очереди → выполняется → завершено.
- [ ] Переключатель "Продолжить при ошибке" наглядно изменяет поведение при сбое одного файла.

<a id="4-calibrate-screen"></a>

## 4. Экран калибровки
- [ ] Выберите образец в качестве калибровочного входа.
- [ ] Установите количество итераций на 1 и нажмите **Найти настройки** (короткая — менее 1 минуты на маленьком клипе).
- [ ] После завершения **Сохранить настроенный профиль как…** становится доступно.
- [ ] Сохраните во временный YAML и подтвердите, что файл существует.

<a id="5-qa-viewer"></a>

## 5. Просмотрщик QA
- [ ] Переключитесь на вкладку **Открыть существующее**; выберите `.qa.html` из шага 1.
- [ ] Отчёт отображается, когда доступен встроенный просмотрщик; вариант через браузер остаётся доступным.
- [ ] **Открыть в браузере** открывает HTML-отчет.

<a id="6-profile-editor"></a>

## 6. Редактор профиля
- [ ] Выберите `cid_aware` из выпадающего списка — таблица заполняется преобразованиями.
- [ ] Измените один параметр, нажмите **Сохранить как…**, укажите новый путь.
- [ ] **Перезагрузить список** подхватывает новый профиль.

<a id="7-history"></a>

## 7. История
- [ ] Проверьте, что запуск из шага 1 появился в таблице истории.
- [ ] Примените фильтр — строки обновляются в реальном времени.
- [ ] **Очистить все** вызывает подтверждение и очищает таблицу.

<a id="8-queue"></a>

## 8. Очередь
- [ ] **Обзор…**+**Инициализировать очередь здесь** в пустой директории — кнопки переключаются из отключенного в включенное состояние.
- [ ] **Добавить файлы…** добавляет образец. Метка статистики показывает в ожидании=1.
- [ ] **▶ Запустить рабочий процесс** — образец обрабатывается; по завершении статистика показывает выполнено=1.
- [ ] **Остановка** во время активного слива происходит чисто.

<a id="9-validation"></a>

## 9. Проверка
- [ ] Шаг 1 → выберите образец + 2 варианта + Генерировать; строки появляются.
- [ ] Шаг 2 → зафиксируйте результат CID для каждой строки (пройдено/не пройдено) и сохраните CSV.
- [ ] Шаг 3 → Выполните корреляционный анализ; в окне вывода отображается отчет.

<a id="10-settings-corpus-theme-switch"></a>

## 10. Настройки + Корпус + переключение темы
- [ ] Переключение темы темная↔светлая — все видимые экраны сразу изменяют оформление.
- [ ] Выберите профиль по умолчанию и Сохраните — повторно откройте Настройки, чтобы убедиться в сохранении.
- [ ] Корпус → Добавить файл → запись появляется. Удалить → строка исчезает.
- [ ] Закройте приложение и запустите заново — последние файлы, выбранный профиль, язык и тема сохраняются после перезапуска.

<a id="11-misc"></a>

## 11. Разное
- [ ] Измените размер окна — нет перекрывающихся виджетов, ярлыки не обрезаются.
- [ ] Раскройте расширенные настройки и журнал активности с помощью фокуса клавиатуры + пробел.
- [ ] При разрешении 980×640 основные действия остаются видимыми при прокрутке страницы.
- [ ] Смена языка: навигация, заголовки страниц и основной рабочий процесс обновляются без пустых элементов управления.
- [ ] Нет ошибок консоли в stderr после нормальной сессии.
